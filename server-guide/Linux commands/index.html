Linux Commands

I've shown in this guide how to configure everything and install software, but I haven't shown you how to use commands.

sudo

Sudo is one of the most important commands. It stands for "superuser do" whatever that came from. It's not often needed in root, but it sometimes is. If you login under your standard user, it allows you to execute root level commands without being in root. Better for security, but because I and this guide don't make a public access root point, it doesn't matter for this as much. In root, you don't need to run sudo apt install and instead you can run just apt install. But it is needed for commands like sudo systemctl and sudo reboot and a few others.
