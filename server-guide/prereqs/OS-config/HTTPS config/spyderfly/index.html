SpyderFly Guide

My goal with SpyderFly is to make an easier and more stable version of NGINX. I've had issues with it. My goals with this software is to make someone wanting to build a website focus on the website and not the site config. I had a lot of headaches with NGINX and it took me a while to get it figured out. One issue I've had with NGINX is that if one config is broken, none will load. There will be a testing command but it will still load the others if one fails. There will also be an auto config baked into the software. Hope to release it soon. I mean, the earliest build of UNIX was made in a week. No joke, look that up. I started the SpyderFly project September 12th, 2026 and just check when this site was last updated to know the time gap. Currently working on beta 2.0 as beta 1.0 was not working right and I decided to start over. I'll keep the beta 1.0 source code though.
