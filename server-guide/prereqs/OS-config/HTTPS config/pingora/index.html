Pingora

I mentioned my NGINX auto config to someone in a Discord server yesterday and they mentioned Pingora. And since then, I can't stop thinking about it. As I mentioned in the previous part, it's developed by Cloudflare in the Rust programming language. Github for it btw. However, it's pretty complicated. NGINX is putting a cube into a square hole compared to Pingora. I started working on learning it via Gemini (It's like an ex I keep going back to). But after Gemini kept complicating it, I went to github and read its docs. Made it make more sense. Here is the source code for version 0.9 I am making no claim of ownership of this, please support the developers on GitHub. We're done with the intro, let's get into this. I also have the quick-start.md here if you'd like to read it.

Like I said in the part before, you have to compile it yourself. Cloudflare gives the code, you build the house. A bit like the Nextcloud LEMP stacks if you read that section. So I will try and make this as concise as I can. To start, let's install some dependencies. Start by running sudo apt update && sudo apt install build-essential clang perl libssl-dev pkg-config curl git cmake -y followed by curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y and finally sudo apt install certbot -y Next you'll need to create the cargo. I recommend doing /etc/pingora. However, you don't just create the directory, the cargo builds it for you. First, run cd /etc and then cargo new pingora followed by cd pingora Now you got the directory. If you run ls or see it via SFTP, you'll see two directories and two files. One should be named Cargo.toml We'll start with that. When you open it, you should see this: 

      [package]
       name = "pingora"
       version = "0.1.0"
       edition = "2024"

       [dependencies]
