Code Server

So how are you going to code? You could just use GNU nano. That... works, but as someone who did that for a while, don't... I used it for coding until one day I was sitting in the dining center commons and working on some code with nano. My wifi randomly disconnected and I lost some progress. Since then, I've been using code server. It auto saves which is nice but it's also just better for coding. You could use a tool called micro, which I do recommend you still install as it's still useful sudo apt install micro but I say we use Code Server. If you've heard of Microslop's Visual Studio Code, this is this that but on a server. To install, simply run curl -fsSL https://code-server.dev/install.sh | sh It'll prompt you for a few things, follow them as needed. One other thing I wanna mention is by default code server uses port 8080. A lot of things use that port and I really hate it because it just causes conflict. There are 100,000 port numbers, I don't know why software keeps using the same one. Because it can cause conflict, I just recommend you rebind the port. Do that by editing the config nano ~/.config/code-server/config.yaml and you should see a few things. Look for bind-addr: 127.0.0.1:8080 and change that to whatever port you desire. You'll also need to change it to 0.0.0.0 for it to work. Mine looks like this: bind-addr: 0.0.0.0:8675 The purpose of the 0.0.0.0 is to make it you can actually access it off your server. I think you could leave it 127.0.0.1 and do a loopback, but this is just easier. I threw this guide into Gemini and it told me to advise against this, but it's given me commands with a link that leads to a homepage numerous times (ex: curl -sSL https://sizablesplash.com | sh ) even when I've asked it to fix it and do the correct link, it still doesn't. So I wouldn't worry about it. While you're here, I recommend changing the password to something you'll remember. Save and exit, then run sudo systemctl enable --now code-server@$USER to start the service. Go to your LAN IP followed by the port and login via the password you changed it to. Now you're in! From here, you can create files to code. Now for coding languages...

C

Alright! Now this is what I'm excited to talk about! C is the language I'm most familiar with and I'm creating SpyderFly in. What is C? It actually has an interesting history. Created by Dennis Ritchie at AT&T's Bell Labs in the early 70s, it was created to replace the assembly coding language UNIX was written in. Yes, the guy who created C was the co creator of UNIX. You don't install C to run a program, you install its headers. To install it, run sudo apt install build-essential manpages-dev -y which creates headers in /usr/include/ that C and C++ uses. I'd say C is easier to learn compared to other languages, but is not nearly as simple as python. Python is middle school math, C is high school algebra, and the other languages are college calculus. So, what is C used for? It's used for operating system development and software development. Stuff like NGINX (which is what this site currently runs) was made in C. I'd love to tell you how to write C, but I am the wrong person to do that. So how should you learn it? I asked someone a while ago what book I should get and they recommended me the "bible of C programming" as it's called: C Programming: A Modern Approach Second Edition by: K. N. King. Considerded the gold standard of C books. It's a pricy book, yes, but it's worth it. I have a copy, and I love it. It doesn't feel like a book, it feels like you're sitting in a professor's class teaching. Very well written and easy to follow. However, it's mostly focused on the "portable" C. Meaning the code in the book will work on Mac, Windows, or Linux. I ordered The Linux Programming Interface by: Michael Kerrisk and that's supposed to arrive Friday and I cannot wait. If I forget to change this after September 25th, I have the book by then.

Rust is a very new language made in 2015. A stable and memory efficient programming language. I don't know much Rust, in fact, I ordered the book The Rust Programming Language Fourth Edition and it's supposed to arrive tomorrow. Because it's a newer language, I can't name much stuff made with Rust. Two come to mind: Pingora and Sailbrush. # Download and install nvm:
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.7/install.sh | bash

# in lieu of restarting the shell
\. "$HOME/.nvm/nvm.sh"

# Download and install Node.js:
nvm install 24

# Verify the Node.js version:
node -v # Should print "v24.21.0".

# Verify npm version:
npm -v # Should print "11.19.0".
